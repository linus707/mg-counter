# mg-counter

제품 사용량 카운터 웹앱 (`index.html` 한 파일). 공개 저장소이므로 **코드만** 있습니다.

- 환자 정보, 병원 이름, 사용량 데이터, 엑셀 파일, API 키는 이 저장소에 올리지 않습니다.
- 사진 속 스티커 바코드는 **AI 없이 사용하는 기기에서** 읽습니다. 사진과 개수는 기기 밖으로 나가지 않습니다.

## 사진 인식
1. **바코드**(GS1)를 별도 스레드에서 읽습니다 (AI 없음, 기기 안에서 처리).
2. 바코드가 없는 스티커는 **인쇄된 REF 글자**(OCR)로 찾습니다 (AI 없음). `ocr/` 파일은 처음 사용할 때 한 번 내려받습니다 (https에서만 동작).
3. **선택**: AI 보강. 본인 Claude API 키를 넣으면, 위 단계로 못 읽은 손글씨 숫자와 놓친 스티커만 AI가 보강합니다. 키는 기기에만 저장되고, 켜면 사진이 Anthropic 서버로 전송됩니다.
- 글자 읽기와 AI는 동시에 돌고, 한 단계가 실패해도 나머지 결과로 계속 진행합니다.
- 읽어 둔 결과는 새로고침해도 남습니다.
