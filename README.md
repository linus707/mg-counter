# mg-counter

제품 사용량 카운터 웹앱 (`index.html` 한 파일). 공개 저장소이므로 **코드만** 있습니다.

- 환자 정보, 병원 이름, 사용량 데이터, 엑셀 파일, API 키는 이 저장소에 올리지 않습니다.
- 사진 속 스티커 바코드는 **AI 없이 사용하는 기기에서** 읽습니다. 사진과 개수는 기기 밖으로 나가지 않습니다.

## 사진 인식 (AI 없음)
- 스티커 바코드(GS1)를 먼저 읽고, 바코드가 없는 스티커는 **인쇄된 REF 글자**(OCR)로 찾습니다.
- 글자 읽기(Tesseract.js)는 `ocr/` 폴더의 파일을 처음 사용할 때 한 번 내려받습니다 (https 주소에서만 동작).
- 손글씨는 읽지 못합니다.
